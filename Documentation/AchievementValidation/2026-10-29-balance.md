## Saves and claims

- All 23 existing receipt IDs remain stable. Numeric suffixes in those IDs are historical and no longer describe the current target.
- Already-claimed receipts remain valid at their original thresholds. Compatibility applies only to receipt validation; an unclaimed achievement must satisfy its new target. Claimed rewards cannot pay again.
- `bestProductCollectionLevel` is an optional saved integer, defaulting to zero in older saves. Each committed command records the highest minimum level held by all eight products, including the state before a prestige reset. Completed level goals remain claimable after prestige. Partial progress toward the next level goal uses current product levels.
- Earnings targets now use `Amount`, including native progress fills, so later-run goals can exceed a 64-bit integer.
- Rewards, receipts and product records use the same existing atomic commit. A persistence failure publishes none of the staged changes.

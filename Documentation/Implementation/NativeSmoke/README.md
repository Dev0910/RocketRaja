# Redesigned Bootstrap/Main smoke test

Run `RocketRaja.Editor.RedesignSmokeValidation.Start()` from compiled, idle Edit Mode with saved scenes. It records and restores the scene setup and QA profile, launches Bootstrap, and exits Play Mode after writing `SmokeResults.txt`. The development harness creates a fresh temporary save with explicitly staged cash/product levels so the full catalogue can be exercised; it does not change a player profile or claim earned pacing.

The first 2 October 2026 Editor run passed 22 checks with no captured runtime errors; its report and timings are preserved as `*-SingleCycle.*`. The current expanded run passes **176 checks** and exercises eight additional full-catalogue Prestige/reveal cycles. It uses actual authored Main controls through `ExecuteEvents`, not physical touch/raycast selection. Separate catalogue, Home and retained-dialog Play Mode suites cover raycast routing. All saved UI object identities survive the repeated run.

`RedesignSamples.json` records the machine, viewport, content version and timings. Each repeated cycle explicitly stages cash/product levels/eligible earnings in the disposable fixture, then uses native Buy All, Prestige and three card reveals, a manual first purchase and a real save. It records full-run UTF-8 size, encode/decode time, cached income, save/command time and managed/native allocations. Staged resources do not establish earned pacing. Editor timings include Editor overhead and are not phone performance or a memory-leak verdict.

Screenshot review found two evidence/presentation issues and drove scoped corrections: startup's brief offline receipt is now acknowledged before the Home capture, and Talent illustrations now reuse the clean product regions instead of an old Rocket crop containing part of a neighbor. The original atlas/image pixels are unchanged.

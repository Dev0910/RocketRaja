Existing shared scalers/fonts/materials are preserved. The entire legacy gameplay hierarchy will remain inactive and inspectable when the replacement is connected; retained settings/privacy/name/recovery routes require focused owner adaptation.

`NativeUI-Baseline.json` inventories current scene, controller, authoring, prefab and font/material bytes with a task-owned local backup directory. Baseline files include pre-existing uncommitted work. New native assets live in `Assets/Game/RedesignUI/`, with focused presentation scripts in Runtime and authoring/verification in Editor. Scene/prefab objects and references are authored only through Unity Editor APIs. No runtime UI factory, prefab instantiation or pool growth is permitted.

## Construction plan

1. Author shared safe-area/header/body/footer and complete Upgrades state with a saved row pool. Body stretches between fixed edge regions; catalogue content alone changes height for virtual scrolling.
2. Add Home and the remaining detail/review/Talent/Prestige/shop/offline states to the same shell. Bind the actual engine projections and transaction IDs, never browser fixture math.
3. Adapt retained routes, then replace Main routing while preserving the legacy root. Verify serialized identities before/after Play Mode and real open/back paths.
4. Compare reference/short/tall/notched layouts, glyphs, motion, failure/recovery and interactions. Then build/profile the integrated prototype on the authorized phone.

The core browser now shares category/product/skill/search scope with immutable Buy All quotes. It reuses a 1,000-entry result buffer and rebuilds membership only on structural state/filter changes; passive cash updates refresh only visible prices/interactability. Available means requirements satisfied, independent of current cash. Upcoming means requirements unmet, Owned is run ownership, and Full exposes every matching authored ID. All rows must remain reachable through the preplaced pool.

Native visual and runtime results will be appended as each saved component is verified. No integrated-native task is closed by this initial plan.
